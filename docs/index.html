killer-skills
Install Skills Source

Claude Code skills that won’t hand you the first draft.

killer-design builds a website and screenshots it. killer-repo rebuilds a repo page and renders it the way GitHub will. killer-council has blind reviewers score the work until it clears a bar they never see. Each one looks at its result, fixes it, and looks again.

Install all three into ~/.claude/skills

PowerShell irm https://raw.githubusercontent.com/Real-Fruit-Snacks/killer-skills/main/install.ps1 | iex
sh curl -fsSL https://raw.githubusercontent.com/Real-Fruit-Snacks/killer-skills/main/install.sh | sh

Every archive is checked against the release’s SHA256 sums first. Both lines bring the web fonts killer-design sets; on Windows the PowerShell line also brings Playwright, Chromium and Mermaid (128 MB), and Node.js or Python if they’re missing, so the skills download nothing later. One skill on its own · Installing offline

Each one is its own download

In Claude Code, type a skill’s name as a command (/killer-repo) or ask in plain words: “make this README better”. Every link here fetches the latest release.

killer-design

Designs and builds a website in hand-written HTML, CSS and a little JavaScript, sets one wow moment on the first screen, then screenshots it at 390, 768 and 1440 pixels and fixes what it sees. Makes the favicon and app icons too.

Asks
Only what it can’t find in the project
Needs
Node.js 20 or later, and Playwright with Chromium: the runtime on Windows, otherwise installed on first use. Fonts come from the font pack
Download killer-design.zip

killer-repo

Rebuilds a GitHub repo page around the project’s most interesting true thing: the README, description, topics, social card, community files and workflows. Runs every claim, renders the README as GitHub will in light and dark at desktop and phone widths, and asks before anything public changes.

Asks
Scope, look, how to land the changes, whether to convene a council
Needs
Node.js 20 or later, Playwright as for killer-design, and the GitHub CLI for the exact render. Offline it makes a labelled approximate one
Download killer-repo.zip

killer-council

Runs a blind scoring council on any piece of work. Fresh agents score it from 1 to 100 with reasons, the leader fixes what they found, and the council reconvenes until the work passes a threshold the members never see. You can take a seat and get the same brief they do.

Asks
Threshold, members, models, your seat, rounds and extras
Needs
Python 3.10 or later. No network beyond Claude Code’s own
Download killer-council.zip

On macOS and Linux, one skill at a time: curl -fsSL https://raw.githubusercontent.com/Real-Fruit-Snacks/killer-skills/main/install.sh | sh -s -- killer-repo

Tested on

  • Windows 11 · Claude Code 2.1.316 · Node.js 24.20.0 · Python 3.14.2: each skill run on a real project
  • Ubuntu 24.04, Windows Server 2025 and macOS 26 in CI on every push: both installers, downloading and from a folder, the packager, fonts.mjs and the council script
  • Windows Server 2025 in CI, with the network cut off: every Chromium script on the packed Node.js, a page in the pack’s fonts, and the council’s tests on the packed Python
  • Not tested: the skills themselves on macOS or Linux, or uploaded to claude.ai

Known issues

  • The runtime, Node.js and Python packs are Windows only. Elsewhere, the first screenshot installs Playwright and Chromium, which needs the network.
  • killer-council’s reviewers work in your folder, not a sandbox. council.py verify catches a change after each round; nothing prevents one.
  • A council that mixes providers needs T3 Code. Elsewhere it offers a mix of Claude models.
  • GitHub has no API for a repo’s social preview, so killer-repo makes the card and tells you where to upload it.

Installer settings

KILLER_SKILLS_VERSION
A release tag, such as v1.2.0. Default: the latest
KILLER_SKILLS_DIR
Where skills go. Default ~/.claude/skills
KILLER_SKILLS_CACHE
Where the packs go. Default ~/.cache
KILLER_SKILLS_RUNTIME
skip: no packs. all: every pack, even with Node.js or Python here
