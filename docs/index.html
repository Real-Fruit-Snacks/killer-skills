Skills

Three skills, each its own download

In Claude Code, type a skill's name as a command (/killer-repo) or ask in plain words ("make this README better"). Every download link below always fetches the latest release.

killer-design

Designs and builds a website in hand-written HTML, CSS and a little JavaScript: landing pages, project sites, portfolios. It sets a direction from the subject, gives the first screen one wow moment, then screenshots the page at phone, tablet and desktop sizes and fixes what it sees. Makes favicons and app icons too.

Asks
Only what it can't find in the project
Needs
Node.js. Installs Playwright into ~/.cache/killer-design on first use
killer-design.zip

killer-repo

Rebuilds a GitHub repo page around one wow moment that shows the project doing its most interesting true thing, plus the description, topics, social card, community files and workflows. It runs every claim, renders the README as GitHub will in light and dark at desktop and phone widths, and asks before anything public changes.

Asks
Scope, look, how to land the changes, whether to convene a council
Needs
Node.js and the GitHub CLI (gh)
killer-repo.zip

killer-council

Runs a blind scoring council on any piece of work. Fresh agents score it from 1 to 100 with reasons, the leader fixes what they found, and the council reconvenes until the work passes a threshold the members never see. You can take a seat and get the same brief they do.

Asks
Threshold, members, models, your seat, rounds and extras
Needs
Python 3.10 or later
killer-council.zip

House rules

Every skill, every time

  • It looks at its own result before you do: screenshots, a rendered README, or scores from reviewers who never see the bar.
  • It asks only what would change the outcome. killer-council and killer-repo ask up front, with a recommended answer for each question, so there are no options to remember.
  • What it couldn't check, or had to assume, is listed in its handoff.
  • Nothing goes public without your OK.
  • Every archive is listed in each release's SHA256SUMS.txt, and the installers check it before replacing anything.

Configuration

Installer settings

In PowerShell, set one with $env:KILLER_SKILLS_VERSION = 'v1.0.0' before the install line. In sh, put it before sh: | KILLER_SKILLS_VERSION=v1.0.0 sh.

VariableEffect
KILLER_SKILLS_VERSIONA release tag to install, such as v1.0.0. Default: the latest release
KILLER_SKILLS_DIRWhere to install. Default ~/.claude/skills

Tested on

  • Windows 11 · Claude Code 2.1.316 · Node.js 24.20.0 · Python 3.14.2: each skill run on a real project
  • Ubuntu 24.04, Windows Server 2025 and macOS 26 in CI on every push: both installers, the packager and the council script
  • Not tested: the skills themselves in Claude Code on macOS or Linux, or uploaded to claude.ai

Known issues

  • The first screenshot runs npm install playwright and may download Chromium, so it needs a network connection.
  • killer-council's reviewers work in your folder, not a sandbox. council.py verify catches a change after each round but can't prevent one.
  • A council that mixes providers needs T3 Code; elsewhere it offers a mix of Claude models.
  • GitHub has no API for a repo's social preview, so killer-repo makes the card and tells you where to upload it.
